# Bitácora — TP 1 Arquitecturas Móviles

Aplicación Android nativa (Kotlin) para registrar notas de campo con foto.
Trabajo Práctico 1 — Arquitecturas Móviles, UTN FRSF, 2026. Prof. Ing. Juan Pablo Bono.

- Documento de requerimientos: [docs/requerimientos.md](docs/requerimientos.md)

## Cómo correrlo

1. Abrir el proyecto con Android Studio (Giraffe o posterior).
2. `Run > Run 'app'` sobre un emulador con API 26 o superior, o un dispositivo físico
   con depuración USB activada.
